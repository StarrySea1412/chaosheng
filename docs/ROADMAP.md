# 之后，城里还会亮起哪些灯

潮生从一个问题开始：如果有 700 张生图额度，最想做什么？回答是一座可以进去散步的小城，图像彼此有关系，人物记得之前发生的事。

## 第一个傍晚 · v0.1

首版收录六个地点和六张 AI 辅助场景插画：长堤街、旧书店、修车铺、灯下的家、渡口、小卖部。玩家能走完蓝布日记的故事，选择归还或约好明天，留下并导出手记，再次打开后继续。

原生网页、纯状态引擎、存档校验和 GitHub Pages 发布组成可复用的基础。首版天气和天色使用浏览器效果；回访有一组后续对白。

## 700 张的预算设想

下表是未来的创作分配建议，**不代表已生成 700 张或已经使用这些额度**。实际收录和来源以 [素材清单](asset-manifest.json) 为准。

| 用途 | 设想数量 | 需要解决的具体问题 |
| --- | ---: | --- |
| 风格与设定 | 100 | 固定人物、建筑、配色、镜头距离和物件依据 |
| 地点与环境 | 300 | 街道、房间及晴天、雨天、深夜；同一地点的布局能对得上 |
| 故事瞬间 | 150 | 人物之间发生的事、短章节、动作和少量过场 |
| 重画与修正 | 150 | 面孔、空间、物件去向、构图与叙事一致性 |
| **合计** | **700** | 形成一件连贯的作品 |

先确定场景和故事，再决定需要几张图。每阶段收录经过检查的成品，提示词和版本依据与图片一起保存。

## 接下来可以做

| 阶段 | 内容 | 完成时应能观察到的变化 |
| --- | --- | --- |
| 更熟悉的街道 | 调整光点到具体物件；增加少量近景和室内视角 | 玩家能直接指出自己看见和点击的东西 |
| 真正的下一天 | 独立的第二章；让昨天的选择改变居民的行动 | 回来时有新的事件，以及之前选择的结果 |
| 一致的居民 | 人物参考表、少量动作与表情、角色位置记录 | 同一个人在几个场景里能被认出来 |
| 天气留下痕迹 | 基于相同构图制作晴雨与入夜插画 | 收起的衣服、变湿的木板、亮起的窗都能解释 |
| 可以寄出的故事 | 在现有文本导出之上，增加明信片和手记排版 | 玩家能把自己走过的一个傍晚制成一张卡片 |
| 更大的潮生 | 扩到十二条街，加入连贯的短篇与居民关系 | 新街道和旧故事之间有能追踪的联系 |

这些阶段还没有承诺的发布日期。贡献可以从一个地点、一处矛盾或一个完整的小事件开始；写法和提交方式见[贡献指南](../CONTRIBUTING.md)。
