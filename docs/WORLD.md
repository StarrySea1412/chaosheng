# 潮生的小城设定

第一章「把名字还给明天」发生在夏日傍晚。小城沿一条通往海边的街展开，店铺之间步行可达。人们有自己的旧物、工作和约定，玩家可以在这些生活之间停一下。

## 地点与居民

| 地点 ID | 名称 | 人物 | 应保持的细节 |
| --- | --- | --- | --- |
| `street` | 长堤街 | 公交司机 | 通向海的街、站牌、长椅、末班车；司机愿意等仍在跑的人 |
| `bookshop` | 旧书店 | 林姨 | 旧木书架、开着的门、热茶；蓝布日记最初遗落在柜台上 |
| `workshop` | 修车铺 | 阿禾 | 旧自行车、两张塑料凳、扳手与雨棚；许舟小时候的车留在这里 |
| `home` | 灯下的家 | 陈叔 | 二楼亮着的窗、钢琴、窗帘与盆栽；傍晚有人听他练琴 |
| `ferry` | 渡口 | 许舟、周伯 | 候船处、潮汐木牌、缆绳与旧渡船；黄色雨衣的许舟在等船，周伯掌船 |
| `grocery` | 小卖部 | 小满 | 冰柜、玻璃汽水瓶、零钱与收据；小满把收据折成纸星星 |

建筑以两层旧房为主，褪色珊瑚色墙面、深青木窗、铁皮雨棚和晾衣绳互相呼应。场景采用哑光水粉、细纸纹和暖窗光，深青阴影衬着晚霞。具体制作约束见 [art-prompts.md](art-prompts.md)。

## 日记的关系

日记的主人是 **许舟**。他小时候生活在潮生，离开多年后回来看几样旧东西：阿禾留着的自行车铃、陈叔傍晚弹的曲子，以及自己的日记。

日记包着蓝布，封面有一角磨白，里面夹一张旧船票。扉页写着「许舟」，最后一页写着「回去以前，去听一次楼上的琴」。林姨允许玩家先拿起本子、确认主人，再带到渡口。

故事的条件是：

```text
旧书店：拿起日记 → 阅读扉页
                         ↓
渡口：归还许舟，或约好明天再见
```

其他地点可以先去，也可以之后再去。归还需要持有日记并已经读过扉页；错误地点不能完成这些行动。约好明天后，玩家替许舟保管一晚，进入下一个傍晚或隔天回访后才可在渡口归还；刷新页面会保留这个约定。两种选择都能收束首章，继续散步也有空间。

拿走日记后，书店的描述会更新。已经归还的日记不能再次领取；已经发现的物件不会重复增加手记。

## 傍晚与回访

`day` 是故事中的第几个傍晚。界面可以主动进入下一个傍晚；在较晚的本地日历日期重新打开游戏，存档恢复也会推进相应天数。地点、发现、手记和日记选择保留，时段回到傍晚。

`time` 有三个值：`0`、`1`、`2`，用于傍晚、蓝调时刻和入夜的场景；切换会循环。`weather` 是 `clear` 或 `rain`。每个地点均有这六种组合的独立插画，保持原有构图与互动道具位置。变化不会取消物件发现或故事选择。

每个地点的日常交谈每天可以执行一次。首版对白分为初访和后续回访两组，第二天之后共用回访文案；独立的每日章节属于后续计划。

## 加内容时的约定

- 人物的话应接着他们正在做的事。修车的人会擦扳手，书店的人会收书；让动作支撑对白。
- 同一物件保持主人、颜色和去向。改变它时同步检查画面、文案和状态。
- 新地点与现有的一段生活相连，例如谁会经过、替谁留过东西、能听见哪扇窗里的声音。
- 一个选择要留下可观察的结果；明天回来时，对话或手记应能记得它。
- 行动条件放在引擎中统一判断，让画面光点与文字按钮指向同一件事。

实现与存档结构以 [`src/world.js`](../src/world.js)、[`src/engine.js`](../src/engine.js) 为准。
